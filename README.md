# Cozneo Venture Private Limited — Website

Static website (HTML, CSS, JavaScript) for Cozneo Venture and its brands:
- **Ajobzio Technologies** — https://ajobzio.com
- **Ajobzio Services** — https://services.ajobzio.com

## Files

```
index.html    Page content
styles.css    All styling (colours: #0b0b0c, #ffffff, #ff0000 · font: Poppins)
script.js     Animations and interactions
assets/       Logo files (original, transparent, web sizes, favicon)
```

## View it

Double-click `index.html` to open it in a browser. No build step or server needed.

## Host it

Upload index.html, styles.css, script.js and the assets folder to any static host (Netlify, Vercel, GitHub Pages, cPanel, etc.).

Before launch, replace the placeholder CIN in `index.html` (search for `TODO`).
